# Cardpeek-ng v1.1.0

This release adds Finnish identity-card analysers and new tools for smart card data decoding.

## Card analysis

- Inspect public metadata and certificates on Finnish eID cards with the new Finnish eID analyser.
- Inspect the travel application on Finnish identity cards with the new Finnish eTravel analyser.
  Use a card access number or machine-readable zone data to establish a PACE session.
  Read personal data, security data, and the facial photograph through secure messaging.
- Read ICAO ePassports with Basic Access Control.
- Use the expanded set of bundled analysers for Calypso, EMV, GSM, MIFARE Classic, Moneo, OpenPGP, Tachograph, Thai eID, and Vitale 2 cards.
- Identify more card types from the updated ATR reference list.

## Analyser development

- Build labelled result trees from BER-TLV data with the native TLV module.
- Decode transport data with the native EN 1545 module.
- Establish PACE sessions and protect card commands and responses with the Lua cryptography API.
- Use SHA-256, AES-256-CBC, and AES-CMAC in addition to the existing cryptographic functions.
- Use new Lua functions for byte construction, conversion, slicing, formatting, and padding.
- Find and remove result nodes with the expanded node API.
- Use library-relative Lua module paths for shared code and reference data.

## Documentation and tests

- Read the expanded analyser development guide and Lua API reference.
- Use the new synthetic Finnish eID and Finnish eTravel fixtures for offline replay tests.

The Finnish eID and eTravel analysers do not validate certificate signatures, revocation status, or passive authentication.
They do not write card data.
