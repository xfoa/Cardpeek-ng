# Cardpeek-ng v1.0.0

This is the initial release of Cardpeek-ng.

## Features

- Read smart cards through PC/SC readers with the desktop or command-line application.
- Inspect APDU commands, responses, and status words in the trace view.
- Analyze cards with the bundled ATR and GSM SIM and USIM Lua analysers.
- Search decoded results and inspect the source data for each value.
- Record and export card traces.
  Import and replay saved traces without a card or reader.
- Export result documents and traces in the native JSON formats.
- Install and manage Lua analysers in the shared library.

Cardpeek-ng sends no telemetry.
Cardpeek-ng does not support legacy Cardpeek scripts, XML documents, or trace captures.
